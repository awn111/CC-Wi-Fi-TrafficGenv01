# macs.txt
#   A plain MAC (AA:BB:CC:DD:EE:FF) = a STATIC / returning user. It recurs every
#   pass in loop modes and gets the --static-prefix hostname (default su-...),
#   so the NMS sees the same client coming and going over time.
#
#   The token  random  = a TRANSIENT client slot. A fresh locally-administered
#   MAC is minted each time it's drawn, with the --hostname-prefix (default
#   wtg-...). Use several for a stream of one-off clients.
#
#   MAC reuse is allowed (no dedup) — returning users are the point.
